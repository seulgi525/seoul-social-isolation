# 🗺️ 서울시 생애주기별 사회적 고립 위험지역 분석

> 서울 **426개 행정동**을 청년·중장년·노년 **3개 생애주기**로 나눠
> 사회적 고립 취약 가능성을 복합위험지수로 수치화하고, 정책 우선순위를 도출한 프로젝트

`Python` `pandas` `geopandas` `Power BI` `공공데이터`

<br>

## 📌 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 기간 | 2026.04.18 ~ 2026.05.20 |
| 형태 | 팀 프로젝트 (동행해조) |
| 출품 | 서울시 빅데이터 활용 경진대회 |
| 분석 단위 | 행정동 (426개) · 생애주기 3구간 |

개인의 고립 여부를 판정하는 모델이 아니라, **어떤 지역과 생애주기에 정책 자원을 먼저 연결해야 하는지** 판단하기 위한 정책지원형 분석으로 설계했습니다.

<br>

## 🎯 문제 정의

고립·고독사 위험은 흔히 노년층에만 집중된다고 여겨집니다. 하지만 청년·중장년도 고립 위험에서 자유롭지 않습니다.

서울 전역을 생애주기별로 나눠 분석하면, **연령대별로 다른 정책 사각지대**를 찾아 선제적으로 자원을 배분할 수 있다고 보고 분석을 시작했습니다.

<br>

## 🔍 분석 과정

### 1. 데이터 수집 및 정합화

서울시 빅데이터캠퍼스 데이터와 외부 공공데이터를 결합했습니다. 데이터마다 행정동 기준·코드·단위·시점이 달라 **정합화가 핵심**이었습니다.

- 행정동 단위 병합을 위한 코드 매핑 및 기준 통일
- 인구·생활이동·인프라(의료·노인복지·교통시설) 데이터 결합
- 결측치 처리 및 이상값 확인

### 2. 복합위험지수 설계

생애주기별로 고립 위험에 영향을 주는 지표를 검토하고, **인구·이동·인프라 3개 축**을 결합한 복합위험지수를 설계했습니다.

| 축 | 주요 지표 |
|---|---|
| 인구 | 1인가구율, 연령대별 인구 비중 |
| 이동 | 생활이동 데이터 기반 외출 빈도 |
| 인프라 | 의료시설·노인복지시설·교통시설 수 |

### 3. 분석 결과
- 생애주기별 고위험 행정동 도출 및 **공간 시각화**
- 외부 취약지표와의 교차검증
- 정책 패키지 매핑 및 **TOP 9 우선순위** 도출

<br>

## 📊 주요 결과물

- 복합위험지수 기반 고위험 행정동 **TOP 20**
- 생애주기별 위험 분포 공간 시각화 (geojson 활용)

## 💡 이 프로젝트에서 보여주는 역량

- 출처·시점·단위가 다른 데이터를 **하나의 분석 단위(행정동)로 정합화**
- 여러 지표를 묶어 **복합지수를 직접 설계**
- 분석을 정책 우선순위라는 **실행 가능한 결론**으로 연결
